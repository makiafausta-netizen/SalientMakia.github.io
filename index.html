Semi-Autonomous Electric Wheelchair
Robotics & Mechatronics Engineer

End-to-end autonomy system combining human joystick control with AI-driven navigation and obstacle avoidance. Deployed on NVIDIA Jetson with real-time sensor fusion and PID motor control for dynamic indoor environments.

Developed a ROS2-based autonomy stack (C++/Python) on Linux, running NVIDIA Jetson and Arduino
Integrated multi-sensor fusion (2D/3D LiDAR, IMU, ultrasonic) for localization, motion planning and motor control
Implemented a Kalman filter system combining IMU and sensor data for trajectory planning and obstacle avoidance
Built simulation environments (Rviz, MATLAB) to model real-world robot behavior and case scenarios
Designed and fabricated shock-resistant mechanical mounts using AutoCAD, FEA, and rapid prototyping
Processed LiDAR point clouds and real-time 2D/3D mapping for obstacle detection and path planning
Designed and wired the full electrical system, powering all onboard components, including the ESP32, Arduino, NVIDIA Jetson, and sensor suite, directly from the wheelchair's existing battery system
